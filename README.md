# Sermon Cut downloads

Signed and notarized installers for Sermon Cut, the macOS app Crosswinds Church uses to cut, export and publish sermons.

Get the latest version from [Releases](https://github.com/Crosswinds-Church/sermon-cut-releases/releases/latest).

- **`SermonCut-<version>.pkg`** installs into Applications. This is the file to deploy from an MDM such as Mosyle.
- **`Sermon.Cut.<version>.dmg`** is the drag-to-Applications disk image.

Requires macOS 14 or later on Apple Silicon. The app signs in to the church's re.word workspace on first launch.
